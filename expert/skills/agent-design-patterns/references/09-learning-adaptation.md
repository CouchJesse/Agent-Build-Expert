# 09 · 学习与适应（Learning and Adaptation）

> 溯源：《智能体设计模式》第 9 章 学习与适应 · 板块：状态与自我提升
> 证据基准：本节内容除特别标注外，均为书中原文确认 [F]。

## 1. 模式定义

学习与适应指智能体根据新经验和数据改变自身的思维、行为或知识，从而突破预设参数的限制，在无需持续人工干预的情况下自主优化表现。它将静态智能体转变为动态进化系统：智能体从简单执行指令，逐步变得更智能，能有效应对动态且不可预测环境中的新情况。「适应」即智能体因学习而表现出的行为或知识变化。

## 2. 工作机制

书中将学习机制分为多条路线 [F]：强化学习（行为试错 + 奖惩）、监督学习（标注样本）、无监督学习（无标签模式发现）、少样本/零样本（LLM 智能体凭极少样本或明确指令快速适应新任务）、在线学习（持续用新数据更新知识）、基于记忆的学习（回忆过去经验，在类似场景调整当前行为）。

两条经典算法基线 [F]：

- **PPO（近端策略优化）**：对策略做小幅、谨慎更新——「裁剪」机制为当前策略设定信任区间，如同安全刹车，防止一次大步更新丢失已学知识、导致性能崩溃。
- **DPO（直接偏好优化）**：跳过奖励模型，直接用人类偏好数据更新 LLM 策略——提升生成受偏好响应的概率、降低不受欢迎响应的概率，规避「奖励模型当裁判」流程中 LLM 钻空子骗高分的不稳定性。

智能体层面的自我改进回路以 SICA（自我改进编码智能体）为代表 [F]：

```
[选择] 回顾历史版本归档及基准表现，按成功率/时间/成本加权选出最优版本
  ↓
[分析] 分析归档发现改进点（催生智能编辑器、AST 符号定位器等自研工具）
  ↓
[修改] 直接修改自身源代码
  ↓
[评估] 基准测试打分，结果记录归档 → 回到选择，循环进化
  ↓
[监督] 异步监督者（另一 LLM）接收调用图/消息/工具日志，
       识别循环或停滞，可干预终止执行
```

进化式编码智能体（AlphaEvolve / OpenEvolve）路线 [F]：快模型生成大量初始方案、强模型深入分析优化，自动评估系统按预设标准打分，反馈驱动迭代进化——OpenEvolve 由控制器协调程序采样器、程序数据库、评估池与 LLM 集群，支持整文件进化、多目标优化与分布式评估；书中给出其实码入口 `OpenEvolve(initial_program_path, evaluation_file, config_path)` → `await evolve.run(iterations=1000)` → 读取 `best_program.metrics`。

## 3. 适用场景与不适用场景

| 适用 ✅ | 不适用 ❌ |
|---|---|
| 动态/不确定/不断变化的环境：预设逻辑难以覆盖新情况 [F] | 静态稳定环境：规则可穷尽，硬编码更可靠 [E] |
| 个性化助手：长期分析用户行为，优化交互协议 [F] | 高确定性/可审计性要求：学习引入行为漂移，难以复现 [E] |
| 交易机器人：按实时市场数据动态调参优化决策 [F] | 实时低延迟场景：学习回路的评估与更新开销大 [E] |
| 反欺诈/推荐/游戏智能体：随新模式与偏好持续调优 [F] | 一次性任务：无重复交互可供经验积累 [E] |
| 自我改进编码智能体：基准驱动的逐版本代码进化 [F] | |

## 4. 选型决策要点

1. **经验法则** [F]：当智能体需在动态、不确定或不断变化的环境中运行时采用本模式；适用于需要个性化、持续性能提升和自主应对新情况的应用。
2. **学习路线选型** [F]：有标注样本→监督学习；有人类偏好数据→DPO 对齐；连续数据流→在线学习；具备记忆回溯→基于记忆的学习；LLM 智能体→少样本/零样本快速适应。
3. **小步更新原则** [F]：借 PPO 的信任区间思想——策略剧烈变化会导致性能崩溃；自我修改必须保留历史版本归档（可回滚、可对比），而非覆盖式前进。
4. **自动评估先行** [F]：AlphaEvolve / OpenEvolve 均以自动评估系统打分作为进化驱动力；没有可靠评估器，学习回路只会放大错误。
5. **安全隔离配套** [F]：能执行 shell/修改源码的智能体必须在专用容器（如 Docker）内与主机隔离运行，并配异步监督者监控行为偏差、可终止执行。

## 6. 反模式与坑点

1. **无自动评估的学习回路** [F]：没有评估器打分就迭代进化，错误策略会被强化——AlphaEvolve 的自动评估系统是其前提条件而非可选项。
2. **覆盖式大幅自我修改** [F]：PPO 的教训——一次大步更新即可丢失已学知识；必须小步修改 + 历史版本归档，保证可回滚、可对比。
3. **自我修改不隔离、不监督** [F]：智能体可执行 shell 命令却直接跑在主机上，文件系统风险极高；须容器化隔离 + 异步监督者识别循环/停滞并可终止。
4. **高估 LLM 的自我创新能力** [F]：书中明确指出，让 LLM 智能体每轮自主提出新颖、创新、可行且有趣的修改仍是当前研究重点——期待完全自主的开放式自我改进并不现实。
5. **把长上下文当学习** [E]：上下文窗口再大也是临时记忆，会话结束即丢失；学习成果必须沉淀到长期记忆（08）才能形成累积进步。

## 7. 与其他模式的组合

- **学习适应 + 记忆管理（08）** [F]：智能体将成功策略、错误和新知识存入长期记忆，未来基于记忆回忆调整行为（基于记忆的学习）。
- **学习适应 + RAG（06）** [F]：知识库学习智能体用 RAG 维护动态知识库，存储成功策略与遇到的挑战，决策时检索参考。
- **学习适应 + 反思（07）** [E]：反思产出改进意见，学习机制将其固化为指令、参数或经验的持久更新，形成「评估→固化」闭环。
- **学习适应 + 目标监控（13）** [F]：监控提供目标达成信号作为评估来源——如交易智能体风险超标时调整策略、学生遇困难时学习系统自动调整策略。
- **学习适应 + 多智能体（10）** [F]：SICA 用子智能体（编码/问题求解/推理）分解复杂任务并管理上下文长度，异步监督者与主智能体并行运行——监督与执行分离是自我改进系统的关键组件。

## 8. 评估指标

- **结果导向**：基准得分提升幅度（逐版本得分曲线，SICA 口径）；目标达成率随时间的改善（AlphaEvolve 式评估分数）。
- **过程导向**：每轮改进有效率（修改后被评估接受的占比）；回滚次数（无效修改频率）；监督者干预/终止次数（过高说明更新策略不稳）。
- **轨迹审查** [E]：学到的经验是否被真实复用（新任务检索并引用了历史成功轨迹）；每次更新是否小步可回滚；失败经验是否被正确隔离而非进入复用库。
