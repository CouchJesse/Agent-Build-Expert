## 1. 平台定位

AgentSpace 是一个旨在推动「智能体驱动型企业」的平台，通过将 AI 集成到日常工作流中提升组织的智能化水平 [F]。其核心功能与定位 [F]：

| 能力 | 说明 |
|---|---|
| 统一搜索 | 为企业的所有数字资产（文档、邮件、数据库等）提供统一搜索能力，并利用先进大模型理解并整合来自不同来源的信息 |
| 专用智能体 | 支持创建和部署专用 AI 智能体——不仅是聊天机器人，还能自主推理、规划并执行多步任务（如自动调研主题、整理带引用的报告、生成音频摘要） |
| 企业知识图谱 | 映射人与文档、数据之间的关系，使 AI 理解上下文，提供更相关和个性化的结果 |
| 无代码构建 | 内置无代码界面 Agent Designer，用户无需深厚技术背景即可定制智能体 |
| 多智能体协作 | 支持多智能体系统，不同智能体可通过开放协议 Agent2Agent（A2A）协议通信与协作，实现更复杂的流程编排 |
| 安全保障 | 基于角色的访问控制（RBAC）与数据加密，保护企业敏感信息 |

最终目标：将智能自主系统深度嵌入企业运营，提升生产力和决策能力 [F]。

## 2. 通过 UI 构建智能体的流程

书中给出的 UI 构建流程（六步）[F]：

1. **进入平台**：在云厂商控制台选择 AI 应用，进入 AgentSpace。
2. **连接服务**：智能体可连接多种服务，包括日历、邮件、HR、项目管理、工单等企业应用平台。
3. **配置提示词（二选一）**：使用平台提供的预设提示词库中的提示词；或自定义提示词，由智能体使用。
4. **启用高级功能**：集成数据存储；接入自有知识图谱或平台内置知识图谱；通过 Web 界面将智能体公开发布；使用分析功能监控使用情况。
5. **交互使用**：完成后即可访问 AgentSpace 聊天界面，与智能体进行交互。

## 3. 要点解读

- **架构理念** [F]：系统架构将复杂的后端流程（自主推理、知识图谱映射）与可视化界面结合，用户通过界面集成数据服务、配置提示词，即可实现定制化、具备上下文感知能力的自动化系统。
- **屏蔽复杂性** [F]：这种方式屏蔽了底层技术复杂性，使用户**无需编程**即可构建多智能体系统。
- **嵌入工作流** [F]：核心目标是将自动化分析与运营能力直接嵌入工作流，提升流程效率和数据驱动分析能力。
- **实操路径** [F]：书中建议参考官方云学习平台上的「使用 AgentSpace 构建生成式智能体」实验课程，获得结构化的实操学习体验。
- [E] 工程判断：无代码平台适合业务侧快速验证与长尾场景；深度定制（自定义工具、复杂编排、私有部署）通常仍需回到代码框架（参见附录 C），两类路径可按「先无代码验证、后框架固化」衔接。
