# 模式选型决策树（完整版）

> 溯源：《智能体设计模式》全书 21 章选型要点与结论章「组合模式构建复杂系统」· 类型：方法论指南
> 证据基准：除特别标注外均为书中原文确认 [F]；标注 [E] 为工程实践推断。
> 用途：任务类型「构建指导」「模式选型」时按本树走查；「生成代码」「评审审核」时用作选型复核基准。

## 0. 走查前置：先定义目标与边界

任何选型前必须先回答（第 11 章目标监控 [F]）：

| 问题 | 未明确的后果 |
|---|---|
| 目标是什么？成功标准可衡量吗（SMART）？ | 目标漂移，无法评估 |
| 失败条件是什么？ | 异常时不知何时止损 |
| 越界清单（禁止做的事）？ | 护栏缺失，高风险操作失控 |
| 高风险操作有哪些（删除/外发/交易/付费）？ | HITL 挂点遗漏 |

**目标未定义清晰前，禁止进入模式选型。**

## 1. 主干决策树

```
Q1 任务能否单步完成（单一行动/工具即可）？
├─ 能 → 不需要编排模式，直接单次提示 + 必要时工具使用(05)
└─ 否 → Q2

Q2 步骤是否已知且固定（开发者可预先枚举）？
├─ 已知且线性 → 提示链(01)
├─ 已知但分支多路径 → 路由(02)
├─ 已知且步骤间相互独立 → 并行化(03)
└─ 未知、需智能体自行探索 → 规划(04)

Q3 是否需要外部数据或现实操作？
├─ 需要实时/私有/精确数据 → 工具使用(05)
├─ 需要事实锚定、防幻觉 → + 知识检索 RAG(06)
└─ 纯内部推理 → 跳过

Q4 输出质量与准确性要求？
├─ 质量优先于速度成本 → + 反思(07)
└─ 速度优先 → 跳过（但评估指标仍须定义，见 19）

Q5 是否跨多轮/多会话保持上下文？
├─ 是 → + 记忆管理(08)（Session/State/Memory 三层）
└─ 单轮任务 → 跳过

Q6 任务是否跨多领域、需多种专长/工具分工？
├─ 是 → 多智能体协作(10)（再选协作形式：顺序交接/并行/辩论/层级/专家团队/批评-审查者）
└─ 否 → 单智能体 + 上述模式组合

Q7 是否涉及高风险操作（删除/外发/交易/付费/不可逆）？
├─ 是 → + HITL(15)（四个干预点：计划审批/工具确认/歧义解决/终审）+ 护栏(18)
└─ 否 → 生产环境仍建议基础护栏(18)

Q8 是否生产部署？
├─ 是 → + 目标监控(13) + 异常恢复(14) + 评估监控(19)
│        + 资源优化(16)（成本敏感时）+ 优先级排序(20)（多任务并发时）
└─ 原型验证 → 最小闭环即可，生产模式延后

Q9 是否需要超越预设参数的持续进化？
├─ 是 → + 学习与适应(09)（成本高，须评估必要性 [E]）
└─ 否 → 跳过

按需补充（横切技术）：
- 复杂问题需显式推理 → 推理技术(17)
- 跨系统/跨平台工具连接 → MCP(11)；智能体互通 → A2A(12)
- 开放性探索/科研发现 → 探索与发现(21)
```

## 2. 高频组合范式（书中案例 [F]）

| 组合 | 适用 | 溯源 |
|---|---|---|
| 规划(04) + 工具(05) + RAG(06) + 反思(07) + 记忆(08) | 自主研究助手（Planner→研究员→写手→评论员） | 结论章组合范式 |
| 规划(04) + 工具(05) + HITL(15) | 深度研究（计划先经用户确认再执行） | 第 6 章 Deep Research |
| 生产者-批评者：反思(07) + 多智能体(10) | 高质量内容生成、代码生成 | 第 4/7 章 |
| 路由(02) + 护栏(18) + HITL(15) | 客服分级处理与升级 | 第 2/13 章 |
| RAG(06) + 反思(07) + 规划(04) | 智能体 RAG（来源验证/冲突调和/多步检索） | 第 14 章 |

## 3. 选型检查清单（走查后自查）

- [ ] 所选每个模式都有明确的「触发信号」理由（复杂度匹配，非堆砌）
- [ ] 有模式被「宁滥勿缺」地加入吗？——能单步不链式、能线性不并行、能单 Agent 不多 Agent [F]
- [ ] 高风险操作全部识别并挂 HITL 了吗？
- [ ] 组合内各模式职责边界清晰吗（规划管拆解、优先级管排序、多智能体管分工）？
- [ ] 每个模式的评估指标（见各分章第 8 节）已纳入整体评估方案吗？
- [ ] 生产横切模式（13/14/19）是否按部署计划补齐？

## 4. 常见误选与纠正

| 误选 | 信号 | 纠正 |
|---|---|---|
| 简单任务上规划(04) | 步骤可预先枚举仍动态规划 | 改提示链(01) [F] |
| 单智能体任务上多智能体(10) | 角色分工后大量空闲 Agent | 回退单智能体 [E] |
| 无质量刚需硬上反思(07) | 延迟翻倍但无准确率收益 | 移除反思，遵循质量优先经验法则 [F] |
| RAG 当万能药 | 知识在训练数据内也检索 | 移除 RAG 或缩小语料 [E] |
| 只加模式不加评估(19) | 无法证明任何组合有效 | 评估指标先行 [F] |
