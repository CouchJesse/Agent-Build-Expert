## 4. 附注（诚实失败声明）

- **附注 A**：`/adp` 斜杠命令为 SKILL.md 中定义的调用契约别名；宿主平台实际触发以技能名 `agent-design-patterns` 或关键词自动路由为准，`/adp` 别名的字面可用性取决于宿主命令注册机制，本阶段无法在打包层验证。
- **附注 B**：5 类任务类型中「构建指导/评审审核/模式选型/讲解模式」为提示驱动型能力，已通过知识文件完整性 + 路由指向有效性做结构化验证；端到端对话实测需技能加载后的真实会话，建议投入使用后以首个真实任务回归验证。
- **头像消耗**：ImageGen 生成 1 张头像，消耗约 5–10 积分。
